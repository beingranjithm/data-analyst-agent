# Data credit and licence

The files in `sample_data/f1_demo/` are a subset (seasons 2021 and 2022, plus the rows they point to) of the Kaggle dataset
**Formula 1 World Championship (1950 - 2024)** by Rohan Rao:
https://www.kaggle.com/datasets/rohanrao/formula-1-world-championship-1950-2020

- Licence shown on the dataset page: **CC0: Public Domain**.
- Original source of the race data: the Ergast F1 database.
- The subset is made by `scripts/build_demo_f1.py`; values are copied unchanged.

The file `sample_data/sales_sample.csv` is made-up data created for this project.

This project is free to use and non-commercial. If you plan to use the Formula 1 data commercially, check the terms of the
original source yourself, because the licence label on a dataset page is the uploader's statement.
