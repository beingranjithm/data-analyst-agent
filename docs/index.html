How it works

Four steps, in order. Nothing is built until you say so.

01

Upload

Add one or more CSV files, or open the Olist e-commerce demo: 8 linked tables of Brazilian orders from November 2017. Every file is cleaned and profiled automatically. The relationships between files — which column points to which row of another — are found without AI, by comparing values, and lookup columns are joined on without adding or losing a single row.

02

Plan and approve

A planner agent reads a text summary of the data (never the raw rows) and proposes a dashboard. You drop what you don't want, then approve it.

03

Build

A chart agent writes the code for each chart and a sandbox runs it. A failed chart gets its error message (scrubbed of data values) and fixes its own code, up to 3 attempts; a rule-based builder fills in anything that still fails, so a dashboard always comes out. It opens with KPI cards that compare the latest period with the one before, chart titles computed from the data, and a data-health note, and downloads as a single web page.

04

Ask

The chat writes pandas code for questions that need real numbers. Every answer has a "Show the calculation" panel with the exact code and result, and an unsupported number gets a visible warning instead of being stated as fact.

What it does

Human in the loop
The AI proposes a dashboard; you approve or drop each chart before anything is built.
Answers you can check
Numbers come from code run on your data, shown in the open — not generated prose. A number that appears in neither the data summary nor a calculation gets a visible warning.
Filters everywhere
Sidebar filters apply to the AI dashboard, the chart gallery, the chart builder and the chat, so "only these orders" works across the app.
Several tables at once
Linked files are joined with left joins, so row counts never change, and a guard blocks the classic mistake of merging two event tables and summing.
Built for free-tier limits
Requests are paced and cached, and a chain of three Gemini models takes over when one's daily quota runs out.
Bring your own key
A visitor's Gemini key lives only in their browser session — never saved, logged, or shared — and "Forget my key" erases it.
Sandboxed code
AI-written code runs in a separate, locked-down process: no network, no stored keys, and a static check before anything executes.

Evaluation

Olist e-commerce demo set (November 2017, 8 tables), answered live by Gemini. Each answer is checked against a result computed independently with plain pandas on the same data.

All questions, first real run1413/14

The one miss is a real finding, not noise. Asked which customer state placed the most orders, the AI counted from the joined order-items table, which only has rows for orders with at least one item, so it said 2,971 instead of 3,012. The raw orders table would have given the right answer. The wrong saved answer was removed rather than patched, so on the public demo that one question needs a Gemini key until it is recorded again.

The checker is automatic: it compares numbers and names against expected values, so it can mark a correct but unusually phrased answer wrong, and it can't judge an explanation.

13/14 is one run on one small dataset, with the same questions the demo shows — not a broad accuracy claim.

Limits on the free host

No live AI code here
The free host doesn't provide the sandbox's file-system lock, so the app refuses to run any new AI-written code there. Only the saved demo code, recorded and checked word for word on my own machine, runs.
Your own key goes partway
On the hosted demo, a visitor's key gets summary-only chat answers and a fixed-rule dashboard — not live calculations.
Process isolation, not a container
Strong enough for a demo with fail-closed checks, but please don't upload confidential data.
CSV only, for now
Excel files aren't supported yet. Up to 15 MB per file and 30 MB in total on the hosted demo, which also goes to sleep when idle, so the first visit can take a moment.

Run it yourself

For live AI dashboards and live calculations, run it on your own machine with a free Gemini API key.

# Python 3.12 or newer
git clone https://github.com/beingranjithm/data-analyst-agent.git
cd data-analyst-agent
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
mkdir -p hello_agent
echo "GOOGLE_API_KEY=your-key-here" > hello_agent/.env
streamlit run app/streamlit_app.py
